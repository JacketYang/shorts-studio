## 3. 核心发现（按重要性）

**F1. 「地板高、天花板低」——所有视频都卡在 ~1,000 次播放。**
前 24 条视频播放全部落在 540–1,871 之间，分布极窄。这说明每条视频都被分发到一个相近规模的测试池，然后**没有任何一条通过测试被扩量**。问题不是发得不够多，而是没有「破圈」的视频。
> 注意：唯一继续观看 > 60% 的视频（16 Balls 10 秒，61.8%）也只有 1,227 播放，所以「继续观看高就一定扩量」不是铁律；这是单样本，需要用后续实验验证。

**F2. 订阅转化是最薄弱环节。** 27,669 播放只有 18 订阅。要到 YPP 早期档（500 订阅），按 0.65/千需要约 77 万播放；若转化提升到 3/千，只要约 17 万。**提高转化比提高产量划算得多。**

**F3. 「可识别旋律 + 视觉节奏」转化最好。** B 系列转化是 A 系列的 2.5 倍。这和该品类的爆款公式一致（见第 5 节：「一个物体、一条规则、逐步升级、旋律越来越清晰」）。

**F4. 开头几天的讲解类视频基本是死的（中位数 56 播放）。** 但要诚实地说：它们恰好是 10/26–10/29 最早发的，那时频道没有任何信号，**时间和题材是混在一起的**，不能断言「讲解类不行」。→ 在工作台里用「探索配额」重新小规模验证，而不是直接放弃。

**F5. 过度依赖单一家族，且存在近重复。**
- A 系列占上传的 26%、播放的 37%，10 天内发了 9 条。
- 存在**同标题重复发布**：`16 Balls, 4 Bins... Can They Sort Themselves?`（11/4 14 秒、11/9 25 秒）、`16 Balls, 4 Bins 🌈 Satisfying Ball Sort`（11/4 13 秒、11/10 29 秒）。
- 目前**没有看到明显的流量惩罚**（重复版本的播放和同系列持平），但也没有任何复利——这是「没被处罚，但被判定为同一类东西」的典型表现。真正的风险在 YPP 审核阶段（见 `02`）。

**F6. 「平均观看百分比 > 100% 但继续观看% 低」= 开头钩子问题。** 例如 Spiral Machine（208% / 33%）、Moving Gate（192% / 32%）、Quick Sort（131% / 24%）。意思是：留下来的人会循环看，但**大多数人在前 1–2 秒就划走了**。→ 优化重点是第一秒的画面和声音，而不是后面的内容。

**F7. 稍长的视频换来更高的观看时长，但没有订阅。** `14 Orbits`（80 秒）单条 6.94 小时、赞 17（最高），但订阅 0。→ 适合作为「观看时长/点赞」型内容，转化需要另外设计（系列感、结尾钩子）。

**F8. 互动为零。** 4 条评论、5 次分享。Shorts 里分享和有实质内容的评论是重要信号。→ 内容设计要内置「让人想评论/转发」的点：预测型钩子（「猜哪个桶先满？」）、争议点（「你听出是哪首曲子吗？」）、首评提问（发布后由系统发出，置顶需在 Studio 手动点一下）。

**F9. 旧的中文视频应处理掉。** 15 条（消防/道路教程、影视解说）与新定位无关；建议批量改为「不公开」而不是删除（可能是你的工作资料）。工作台要有「批量改隐私」功能。

**F10. 发布频率合理（约 1.9 条/天）。** 问题不在频率；先别盲目加量。

## 4. 增长目标（以 4 周为一个周期）

| 指标 | 基线 | 4 周目标 | 12 周目标 |
|---|---|---|---|
| 继续观看% 中位数 | 44% | ≥ 52% | ≥ 60% |
| 订阅/千播放 | 0.65 | ≥ 2 | ≥ 3 |
| 破圈率（单条 ≥ 10k 播放） | 0 / 34 | ≥ 1 / 15 条 | ≥ 1 / 10 条 |
| 回访观看者占比 | 0.2% | ≥ 1.5% | ≥ 3% |
| 每千播放 评论 / 分享 | 0.14 / 0.18 | ≥ 0.6 / 0.6 | ≥ 1 / 1 |
| 同模板连续重复（见 `02`） | 存在 | 0 违规 | 0 违规 |
| 累计订阅 | 15 净增 | 100 | 500（YPP 早期档的订阅门槛） |

YPP 门槛（2026 资料）：早期档 500 订阅 + 近 90 天 3 个公开上传 + （3,000 观看小时 或 90 天 300 万 Shorts 观看）；完整档 1,000 订阅 + （4,000 小时 或 90 天 1,000 万 Shorts 观看）。**当前不要为了变现改变内容策略**，先把订阅和破圈做起来。

## 5. 这个品类的参考频道与爆款公式

通过搜索找到的同类频道（**订阅数/播放数未逐一核实，工作台上线后用 API 自动核实**）：

| 频道 | 观察到的特点 | 可借鉴点 |
|---|---|---|
| satisfying.ba11s | 「Will the Ball Escape?」类爆款的起点之一；资料称一条 Shorts 4 个月 6,700 万播放 | 一个物体 + 一条规则 + 逐步升级 |
| CodeCraftedPhysics | 「球能逃出圆环吗」一条 3 个月 440 万播放 | 悬念型标题 + 可再生墙体 |
| Jack's Physics | 「每次弹跳变大变快」一条 5 个月 94.5 万播放 | 单一规则的极端升级 |
| FuncFlow | 同期同类 | 观察其题材更替速度 |
| The Peaceful Physics | 「每条是一个新游戏，看、猜、放松」，每天更新，声音由触碰产生 | 「猜」的互动 + 稳定日更 |
| JollyMathFist | 霓虹轨迹 + 椭圆/三角台球 + ASMR 声音，约 60 秒 | 视觉辨识度（霓虹光轨）+ 声音统一风格 |
| Satisfying Physics Simulation | 自述全部由自写 Python 逐帧渲染，声音来自模拟本身 | 与你的技术路径最接近，重点看其节奏 |
| BallEngine（工具站，不是频道） | 面向创作者的小球模拟器 | **说明这个品类已被工具批量化，同质化严重，必须靠差异度取胜** |

长视频概念来源（可做灵感，不是对标）：3Blue1Brown 的方块碰撞算 π、Veritasium 类物理悖论。

**爆款公式（来自「Will the Ball Escape」品类资料 + 你的数据）：**
1. 一个明确的对象 + 一条一句话能说清的规则；
2. 升级/加速/变大，**让观众想看到极端状态**；
3. 声音由碰撞触发，旋律越来越清晰（你的 B 系列已验证）；
4. 结尾能接回开头（循环），平均观看百分比 > 100%；
5. 品类已饱和 → **差异化靠「规则/场景/旋律」的组合创新**，不是换颜色。

工作台里「参考频道库」模块会：订阅这些频道的 RSS（不耗配额）→ 用 `videos.list`（1 单位/50 条）取统计 → 计算「相对该频道中位数的倍数」，找出**离群爆款**，作为选题输入。详见 `05`。

## 6. 对工作台设计的直接要求（从诊断反推）

1. 差异度守卫必须强制（F5）。
2. 每条视频必须有「钩子」字段：第 0–1.5 秒的画面/声音设计，并在 QA 里检查首帧（F6）。
3. 循环结尾是模板的内置选项（F6）。
4. 互动设计字段：首评 `first_comment`、预测型钩子（F8）。
5. 「系列/集数」是一等公民：给回头客一个理由（F2/F3）。
6. 数据回流要用 `engagedViews / views` 估算继续观看率，并按模板/旋律/钩子归因（见 `06`）。
7. 批量改隐私/删除（F9）。
8. 支持导入 Studio 导出的 CSV（就是你这份表格的格式）作为 API 不可用时的降级数据源。

## 7. 第二个频道的定位建议

不要做第一个频道的换皮版（会被视为矩阵号搬运）。可选方向（共用渲染技术，但题材/视觉/声音/文案全部不同）：
- 频道 B：**算法与数学的声音**（排序、素数、傅里叶、混沌），偏知识感，深色极简视觉；
- 频道 C：**抽象 ASMR 动力学**（磁力摆、磁流体风格粒子、弹簧、织物），无旋律、纯质感声音。
频道 A（当前）：**旋律球 / 物理小游戏**，主推 B 系列方向。
