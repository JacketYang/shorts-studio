# 03 产品需求文档（PRD）

## 1. 产品定位与原则

**定位**：个人/小团队使用的「Shorts 内容工厂 + 发布台 + 频道管理台」。单用户起步，数据模型预留多用户。

**原则**
1. **转化优先于产量**：所有功能围绕「更高的继续观看率、订阅转化、破圈率」。
2. **制作 → 发布 一条流水线**，一个页面能看到每条视频走到了哪一步。
3. **差异度是硬约束**（见 `02`）。
4. **频道硬隔离**（见 D8）。
5. **半自动优先**：先让人轻松审核，再逐步放开自动。
6. **可回放、可审计**：每条视频能追溯到 Spec、种子、模板版本、渲染日志、审核记录。同一个 Spec + 同一个种子 + 同一个模板版本 = 逐帧相同的视频（确定性渲染）。
7. **成本可控**：AI 与云资源都有预算上限，超限自动停止并告警。

## 2. 角色

- **运营者（你）**：配置频道、审核、看数据。
- **系统（自动化）**：定时生成、渲染、检查、发布、同步数据。
- **AI 助手**：生成创意/Spec、起标题、检查、起草评论回复（只有建议权，没有发布权，除非信任等级允许）。

## 3. 核心用户流程

### 3.1 每日半自动流程（默认）

```
[T-48h] 规划器按「内容日历 + 差异度规则 + 探索配额」为每个频道排好未来 N 天的槽位
[T-36h] 池子里不足 → 自动调用 AI 生成 Spec 批次 → 导入 → 校验
[T-30h] 渲染任务派发到 Worker → 产出 mp4 + 封面帧 + 音频 + 指纹
[T-26h] 自动 QA（规则 + 视觉抽检）+ 差异度评分
[T-24h] 进入审核队列（手机可审）；通知你「明天的 3 条已就绪」
[T-2h]  审核通过的上传为 private + publishAt（YouTube 到点自动公开）
[T+1h/24h/48h/7d] 抓取数据快照 → 打标签（爆款/正常/失败）→ 回流到模板/旋律/钩子评分
```

### 3.2 手动补充素材流程

运营者在「创意库」点「导入 JSON」→ 拖入 AI 生成的 `specbatch` → 逐条校验（显示每条的错误与警告）→ 进入「待渲染」池。

### 3.3 爆款复用流程

某条视频被标记为爆款 → 点「做下一集」→ AI 生成 3 个变体 Spec（强制通过差异度守卫）→ 进入渲染。

## 4. 功能模块与优先级

优先级：**P0 = 第一阶段必须；P1 = 第二阶段；P2 = 之后。**

### 4.1 频道与账号（P0）
- 连接 YouTube 频道（OAuth），一个工作台可挂多个频道；一个频道一份凭据（加密存储）。
- 频道档案 `channel_profile`：定位/语言/视觉识别（调色板家族、片头标识）/允许使用的模板/配乐风格/发布时区与时间窗/日发布上限/差异度规则覆盖/审核模式与信任等级/AI 预算。
- 频道健康面板：API 配额使用、凭据状态（是否过期）、最近错误。

### 4.2 素材与创意库（P0 导入，P1 自动补货）
- **导入**：`specbatch`/`ideabatch`/`melody`/`trendimport`（JSON，见 `07`），逐条校验，部分成功可导入，错误清单可下载。
- **模板目录**：展示每个模板的参数 schema、示例、历史表现。
- **旋律库**：公版曲目（MIDI/JSON）、生成旋律；记录授权来源、上次使用时间。
- **补货策略**：每频道设置「待发布池最少天数」（默认 5 天）。低于阈值自动触发 AI 生成（P1）。
- **创意状态机**：`idea → spec_ready → queued → rendering → rendered → qa_failed | in_review → approved | rejected → scheduled → published → measured`。

### 4.3 制作（P0）
- 渲染任务队列（状态/日志/耗时/失败重试，最多 2 次，失败原因分类）。
- 预览：在线播放 mp4、查看 8 个关键帧、查看旋律事件时间线、查看 Spec。
- 「重新渲染变体」：改种子/改某个轴再渲染，仍通过差异度守卫。
- 批量渲染：一次选多个 Spec，按并发上限排队。
- 确定性：同输入同输出（哈希可校验）。

### 4.4 自动 QA 与差异度（P0 规则检查；P1 视觉 AI 抽检）
- 规则检查：分辨率/时长/帧率/音量（LUFS）/静音/黑帧/文字安全区（Shorts UI 遮挡区）/首帧是否有内容/标题长度。
- 钩子检查：前 1.5 秒必须有运动和声音（能量阈值）。
- 差异度评分（见 `02`）。
- P1：视觉抽检（取 5 帧 + 标题给视觉 LLM，问：钩子是否清晰？文字是否可读？有无不当内容？）。

### 4.5 审核（P0）
- 审核队列：大卡片播放 + 关键信息（标题、钩子、差异度分、风险提示）；快捷键/手机滑动：通过、驳回（必选原因标签）、改标题后通过、重新生成。
- 驳回原因标签（`hook_weak`/`too_similar`/`audio_bad`/`visual_bad`/`title_bad`/`risky`/`other`）**回流**训练评分与生成提示。
- 三档审核模式（按频道配置）：
  - **L0 全手动**：所有视频必须人工通过。
  - **L1 半自动**：自动检查与差异度全部通过 + 风险低 → 倒计时 N 小时（默认 8h）无人驳回则自动通过。
  - **L2 全自动**：通过自动检查直接排期，仅抽检（默认 20% 进入人工队列）。
  - 升级条件建议：L0→L1：最近 20 条人工通过率 ≥ 90% 且无政策问题；L1→L2：最近 40 条自动通过的无一被事后人工撤回。任何一次「事后撤回/政策警告」自动降一级。
- 通知：邮件/Telegram（P1），可在通知里直接「通过/驳回」。

### 4.6 发布与排期（P0）
- 内容日历（周视图/月视图，按频道），拖动调整。
- 自动选槽：时间窗内、避开同频道其他视频 ≥ 3 小时、按历史表现倾向。
- 上传：private + `publishAt`；元数据（标题/描述/标签/类别/语言/是否儿童内容/是否含合成内容）；发布后自动发「首评」（YouTube API 不支持置顶，置顶需运营者在 Studio 手动点，审核/发布页给出提示）；加入播放列表（系列）。
- 失败处理：配额不足顺延到次日；网络失败按指数退避重试；**失败重试不能造成重复上传**（上传前记录幂等键，重试前先查询远端是否已存在）。
- 配额仪表：今日已用/剩余、预计可发布条数。
- 紧急操作：一键暂停频道所有发布；一键撤回（改为 private）。

### 4.7 频道管理（P0 视频列表/改隐私/数据；P1 评论；P1 删除）
- 视频同步：用 uploads 播放列表（便宜）同步远端视频，与工作台内部条目关联。
- 视频操作：改标题/描述/标签、批量改隐私（旧视频治理）、删除（二次确认 + 软删除日志）、加入播放列表。
- **评论中心（P1）**：收件箱（按视频/时间/是否已回复）、AI 起草回复（遵循频道语气）、一键回复、隐藏/标记垃圾；提问式首评由系统发布，置顶需手动。不做自动群发式回复（有垃圾风险）。
- **数据看板（P0/P1）**：单视频 24h/48h/7d 快照；按模板/旋律/钩子/标题模式聚合；订阅转化；继续观看率估算；对比频道基线。
- **导入 Studio 导出 CSV（P0）**：就是你这份表格的格式，API 分析不可用时的降级。

### 4.8 洞察与趋势（P1）
- 参考频道库：添加频道 → RSS 监控 → 离群爆款榜。
- 趋势信号库：来源多样（YouTube mostPopular/搜索、Google Trends、Reddit、维基百科浏览量、手动导入 TikTok/IG 榜单 JSON）。
- 「选题建议」：把趋势信号 + 自家数据 + 参考爆款，让 AI 生成 `ideabatch`。
- 模板/旋律/钩子记分牌与探索实验（见 `05`）。

### 4.9 设置（P0）
- 频道、档案、规则、渲染 Worker、存储、AI 模型与预算、通知、导入导出（全量数据导出 JSON/CSV）。

### 4.10 暂不做（明确排除，避免范围蔓延）
- 应用内视频剪辑器/时间轴编辑器；
- 真人素材/AI 写实视频生成；
- 自动评论刷量/互赞/任何违反平台政策的增长手段；
- TikTok/IG 自动发布（P2，另行评估审核流程）。

## 5. 页面清单（信息架构）

| 路由 | 页面 | 优先级 |
|---|---|---|
| `/` | 总览（当前频道的今日流水线、告警、KPI） | P0 |
| `/channels` | 频道列表与 OAuth 连接、档案 | P0 |
| `/library` | 创意库：Spec 列表/导入/模板目录/旋律库 | P0 |
| `/studio` | 制作：渲染队列、预览、变体 | P0 |
| `/review` | 审核队列 | P0 |
| `/calendar` | 发布日历与排期、配额仪表 | P0 |
| `/videos` | 频道视频管理（同步/改隐私/删除） | P0 |
| `/comments` | 评论中心 | P1 |
| `/analytics` | 数据看板与记分牌 | P0 简版 / P1 完整 |
| `/insights` | 参考频道、趋势、选题建议 | P1 |
| `/settings` | 设置 | P0 |

全局：右上角**频道切换器**；所有列表默认只显示当前频道；「全部频道」只在总览与配额页出现。

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 可靠性 | 所有任务幂等；任务表是唯一真相，进程崩溃后可恢复；定时器每分钟 tick 一次，重复 tick 无副作用 |
| 安全 | 全站登录保护；OAuth 令牌 AES-GCM 加密；密钥只在服务端环境变量；Worker 回调带 HMAC 签名；所有外发请求不含用户令牌日志 |
| 成本 | AI 月预算硬上限、渲染分钟预算、R2 存储水位告警（≥ 8GB 提醒，见 `04` 的生命周期规则） |
| 性能 | 单条 30s 1080×1920 渲染 ≤ 5 分钟（CPU）；审核页首屏 ≤ 2s；视频用 R2 预签名 URL 播放 |
| 可观测 | 每个任务有结构化日志；失败原因分类；每日摘要 |
| 可移植 | 渲染 Worker 与控制面只通过 HTTP + 对象存储通信；可迁移到其他云 |
| 合规 | 遵守 YouTube API 服务条款与开发者政策：不缓存超期的 API 数据、不用于违禁用途 |

## 7. 数据保留
- 成片 mp4：发布后保留 14 天于 R2，之后只保留 Spec + 指纹 + 封面帧（可由 Spec 确定性重渲）；
- 未发布的被驳回成片 3 天后清理；
- 指标快照永久保留（体积小）。
