## 3. 范围风险

- 需求很大（制作 + 发布 + 频道管理 + 趋势 + 学习 + 多频道）。**真正的最小闭环只有 Phase 1**；其余都应在 Phase 1 验收后才开始。
- 最容易被编码 AI 过度设计的地方：差异度检测（先做规则 + 告警）、趋势抓取（先手动导入）、自动化评论（先不自动）。主 Prompt 已明确禁止/延后。
- **最大的非技术瓶颈不是代码，而是内容质量**：当前数据显示「所有视频卡在 ~1,000 播放」，工作台只能让产出更稳定、更可迭代，不能自动保证破圈。所以钩子 QA、探索配额、数据回流是核心而不是装饰。

## 4. 是否需要整合成一个 Prompt？

**结论：不合并，保持「文档 + 主 Prompt + 分阶段 Prompt」。**
- 合并后太长，约束被稀释；编码 AI 在仓库里可以直接读 `docs/`；
- 已在 `09` 提供：主 Prompt（每次会话都带）、Phase 1/2/3 任务 Prompt、模板开发 AI 专用 Prompt（可并行）；
- 建议交付顺序：先发「主 Prompt + Phase 1」；同时另开一个会话发「模板开发 Prompt」（它依赖 `07` 与 `05` §2.2，不依赖控制面）。
